# 🍫 Chocolate Sales Analysis Dashboard

## 📌 Project Overview

This project presents an interactive **Chocolate Sales Analysis Dashboard** built using **Power BI**. The dashboard provides insights into sales performance, revenue trends, product categories, customer behavior, and regional performance using data visualization techniques.

The objective of this project is to transform raw sales data into meaningful business insights that help stakeholders make data-driven decisions.

---

# 📊 Dashboard Highlights

* Interactive and dynamic Power BI dashboard
* Sales performance analysis
* Revenue and profit tracking
* Product-wise sales insights
* Regional and customer analysis
* KPI tracking and business metrics
* Trend analysis using visual charts and graphs

---

# 🛠️ Tools & Technologies Used

* **Power BI** – Data visualization and dashboard creation
* **Microsoft Excel / CSV Dataset** – Data source
* **Power Query** – Data cleaning and transformation
* **DAX (Data Analysis Expressions)** – KPI calculations and measures
